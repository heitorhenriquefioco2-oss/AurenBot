AURENBOT

Notificações

Receba os avisos no Windows e no Android ao mesmo tempo. O endereço e a chave de cada dispositivo ficam salvos separadamente neste perfil do Chrome.

Windows

Abra o AurenBot Alertas no PC e copie o endereço. Na VPS, use o IP Tailscale do PC. Copie a chave da aplicação no PC. Ela fica salva mesmo se você desmarcar este dispositivo.

Android

Abra o aplicativo no celular, permita notificações e toque em Iniciar receptor. Use o IP Tailscale do celular. Copie a chave exibida no aplicativo Android. Ela é independente da chave do Windows.

Conecte a VPS e o celular ao Tailscale. Para receber com a tela apagada, permita uso de bateria sem restrições para o aplicativo e o Tailscale. Som e vibração são controlados no celular.

Marque os dois dispositivos para receber simultaneamente. Desmarcar um dispositivo não apaga seu endereço nem sua chave.
Carregando configuração…

Cada receptor precisa estar ligado. Se um dispositivo estiver offline, o outro continua recebendo os avisos. Nenhuma imagem do CAPTCHA é enviada. Resolva a verificação manualmente pelo VNC.
